# Как устроен Country Search

## Отмена устаревших запросов

При каждом изменении поля ввода `setQuery` в searchController сразу вызывает `abort()` у предыдущего контроллера. Это происходит до запуска нового таймера `debounce`.

В runCountrySearch сигнал отмены объединяется с таймаутом в 10 секунд через AbortSignal. Объединённый сигнал передаётся в `fetch`. Обычная отмена даёт `AbortError`.

## Задержка debounce

Поиск начинается после **350 мс** без изменений в поле. При наборе названия подряд отдельные буквы обычно приходят быстрее, и [`debounce`](src/debounce.ts) сбрасывает таймер. Пользователь получает результат после короткой паузы, а API не получает запрос на каждую введённую букву.
